## Continuing earlier conversations

```powershell
node .\babel-cli\dist\index.js resume
```

Inside a session, `/resume` continues a persisted conversation. Session state
is local to your machine.

## Checkpoints (in-session)

```text
/checkpoint    mark a restore point
/restore       return to a checkpoint
```

## Undo (CLI only)

```powershell
node .\babel-cli\dist\index.js undo
```

`undo` restores the last checkpoint. **The TUI has no `/undo` command** — this
split is intentional. Do not trust any documentation (including older Babel
prose) that suggests typing `/undo` inside a session; use `/checkpoint` and
`/restore` in-session, or CLI `undo`.

## Limits to know

- Sessions and checkpoints are local runtime state, not a distributed
  history; treat them as part of your working copy.
- Checkpoints restore code state; they do not "unsend" provider API calls or
  revert your provider account spend.
