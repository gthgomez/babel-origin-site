Deep mode is Babel's higher-ceremony path: it loads the governed pipeline
(OLS v9), an adversarial QA reviewer, and the CLI executor with verification
gates.

```powershell
node .\babel-cli\dist\index.js deep "Harden the migration path and verify it"
```

## What Deep adds over Chat

- An orchestrator and pipeline stages (QA review, executor loop).
- A verifier contract finalize step rather than the chat honesty gate alone.
- More structure intended for riskier changes.

## What Deep does **not** guarantee

This is important and stated in the product's own status documentation:

- **Deep is not a blanket reliability upgrade.** Route availability does not
  mean Deep is more reliable than chat for ordinary tasks.
- Deep is still maturing. It is under the same active-qualification boundary
  as the rest of the ordinary coding loop.
- More ceremony means more time and more provider cost per task, not a
  correctness score.

## When to reach for Deep

- Changes where an independent adversarial review pass is worth its cost.
- Tasks where you want the full governed pipeline's gates, not just the chat
  completion honesty gate.

Otherwise start with [Chat](/docs/using-babel/chat/) or
[Plan](/docs/using-babel/plan/).
