Babel is a local coding agent with inspectable instructions, explicit permissions,
and visible verification results. This documentation is task-oriented: pick what
you are trying to do.

- **Install it** → [Install from source](/docs/getting-started/install/)
- **First run** → [Quickstart](/docs/getting-started/quickstart/)
- **Something is broken** → [Troubleshooting](/docs/getting-started/troubleshooting/)
- **Daily use** → [Chat](/docs/using-babel/chat/), [Plan](/docs/using-babel/plan/), [Deep](/docs/using-babel/deep/)

Babel is pre-1.0: ordinary coding-loop reliability is under active qualification.
See the product [status page](/status/) for what exists in source, what has been
tested, and what is actually distributed.

Deep runtime reference material — full command catalogs, schemas, and
architecture — stays in the [Babel repository](https://github.com/gthgomez/Babel).
These guides summarize; each page lists the exact source it was written from.
