Babel is **not published as an npm package**. The supported installation path is
a source clone. Install commands that fetch a `babel`/`babel-harness` package
from the npm registry are not Babel Harness. Separately, the v0.1.1 GitHub
release publishes an **unsigned Windows x64 portable preview** — a real,
checksummed asset that is not a signed or installer-qualified release. See
[Desktop](/docs/interfaces/desktop/) for its exact scope.

## 1. Clone and build

PowerShell:

```powershell
git clone https://github.com/gthgomez/Babel.git
cd Babel
npm --prefix .\babel-cli ci
npm --prefix .\babel-cli run build
```

macOS / Linux:

```bash
git clone https://github.com/gthgomez/Babel.git
cd Babel
npm --prefix ./babel-cli ci && npm --prefix ./babel-cli run build
```

The authoritative package root is `babel-cli/` — the repository has no root
`package.json`. After the build, commands run as
`node .\babel-cli\dist\index.js` (or `node ./babel-cli/dist/index.js`) from
the repository root. `babel` is not assumed to be on PATH.

## 2. Verify the build

Run the no-key diagnostic — it intentionally reports missing prerequisites and
does not need a provider key:

```powershell
node .\babel-cli\dist\index.js doctor
```

Expected state: the command runs and prints environment findings. Missing
provider keys or Docker are legitimate findings at this stage, not failures of
the install. Exit zero is not the only legitimate documented outcome.

## 3. What about Desktop?

A Windows x64 portable preview (Desktop shell plus the authoritative CLI) is
published as an **unsigned** asset in the v0.1.1 GitHub release, with the ZIP's
SHA256 published in `SHA256SUMS`. There is **no published Setup.exe**, no code
signing, and no automatic updater. Verify the checksum before running it. See
[Desktop](/docs/interfaces/desktop/) for what exists and what is explicitly
unqualified.

## Requirements recap

| Requirement | Needed for |
| --- | --- |
| Node.js 22.19+ (22.x) or 24.13.1+ (24.x) | Building and running the CLI |
| Git | Cloning the source |
| A provider API key | Model-backed sessions (not for inspecting the harness) |
| Docker + sandbox image, or an isolation decision | Mutating work under the default `safe_repo` profile |
